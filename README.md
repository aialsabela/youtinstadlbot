# ربات دانلودر یوتیوب و اینستاگرام (رایگان و متن‌باز)

این ربات با کتابخونه‌ی رایگان [yt-dlp](https://github.com/yt-dlp/yt-dlp) کار می‌کنه — نیازی به هیچ سرویس یا API پولی نیست.

## مراحل راه‌اندازی

### ۱. ساخت ربات در تلگرام
1. توی تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` رو بزن و اسم و یوزرنیم دلخواه رو وارد کن.
3. توکنی که بهت می‌ده رو کپی کن (چیزی شبیه `123456:ABC-DEF...`).

### ۲. نصب پیش‌نیازها
روی سیستم یا سروری که پایتون ۳.۹ به بالا داره:

```bash
pip install -r requirements.txt
```

اگر خطای مربوط به ffmpeg گرفتی (برای بعضی فرمت‌های ویدیو لازمه)، نصبش کن:

```bash
# اوبونتو / دبیان
sudo apt install ffmpeg

# مک
brew install ffmpeg

# ویندوز: از سایت رسمی ffmpeg دانلود کن و به PATH اضافه کن
```

### ۳. تنظیم توکن
توکنی که از BotFather گرفتی رو به‌عنوان متغیر محیطی ست کن:

```bash
export BOT_TOKEN="123456:ABC-DEF..."
```

(روی ویندوز: `set BOT_TOKEN=...`)

یا مستقیم توی فایل `bot.py` جای `PUT_YOUR_TOKEN_HERE` بذارش (فقط برای تست شخصی، برای انتشار عمومی توصیه نمی‌شه).

### ۴. اجرا

```bash
python bot.py
```

اگر پیام "Bot started polling..." رو دیدی یعنی ربات فعاله. حالا برو توی تلگرام سراغ ربات خودت، `/start` بزن و یه لینک یوتیوب یا اینستاگرام بفرست.

## محدودیت‌های مهم

- **حجم فایل**: ربات‌های تلگرام معمولی (بدون Local Bot API Server) نمی‌تونن فایل بالای ۵۰ مگابایت بفرستن. برای فایل‌های بزرگ‌تر باید [Local Bot API Server](https://github.com/tdlib/telegram-bot-api) رو خودت راه‌اندازی کنی (حد مجاز می‌ره تا ۲ گیگابایت).
- **لینک‌های خصوصی/محدود**: ویدیوهای خصوصی، حذف‌شده یا محدود به کشور خاص قابل دانلود نیستن.
- **اینستاگرام**: پست‌های خصوصی نیاز به لاگین دارن؛ برای این حالت باید کوکی مرورگر رو به yt-dlp بدی (به مستندات yt-dlp سر بزن، بخش `--cookies-from-browser`).
- yt-dlp مرتب آپدیت می‌شه چون یوتیوب/اینستاگرام گاهی ساختارشون رو عوض می‌کنن؛ با `pip install -U yt-dlp` به‌روز نگهش دار.

## میزبانی رایگان (Hosting) از طریق گیت‌هاب

### چرا کلادفلر نه؟
Cloudflare Workers محیط جاوااسکریپت/V8 با محدودیت زمان اجراست و به پایتون، subprocess یا فایل‌سیستم دسترسی نداره — پس نمی‌تونه `yt-dlp` و `ffmpeg` رو اجرا کنه. برای این نوع ربات باید از پلتفرمی استفاده کنی که ماشین واقعی پایتون بهت می‌ده: **Railway** یا **Render**.

### مرحله ۱: آپلود روی گیت‌هاب
```bash
cd ytbot
git init
git add .
git commit -m "Telegram YouTube/Instagram downloader bot"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

### مرحله ۲: دیپلوی روی Railway (پیشنهاد اول)
1. برو [railway.app](https://railway.app) و با گیت‌هاب لاگین کن.
2. **New Project → Deploy from GitHub repo** رو بزن و ریپو رو انتخاب کن.
3. توی تب **Variables**، متغیر `BOT_TOKEN` رو با توکنی که از BotFather گرفتی اضافه کن.
4. Railway خودکار فایل `railway.json` و `nixpacks.toml` (که ffmpeg رو هم نصب می‌کنه) رو تشخیص می‌ده و دیپلوی می‌کنه.
5. توی لاگ‌ها دنبال `Bot started polling...` بگرد؛ یعنی آماده‌ست.

### مرحله ۳: دیپلوی روی Render (جایگزین)
1. برو [render.com](https://render.com) و با گیت‌هاب لاگین کن.
2. **New → Web Service** رو بزن و ریپو رو انتخاب کن (فایل `render.yaml` خودکار تنظیمات رو می‌خونه).
3. متغیر محیطی `BOT_TOKEN` رو توی بخش Environment وارد کن.
4. دیپلوی کن. توجه: پلن رایگان Render بعد از مدتی بی‌فعالیتی (اگه به‌عنوان وب‌سرویس اجرا بشه) خواب می‌ره؛ کد یک سرور سبک HTTP برای health-check داره که این مشکل رو تا حدی مدیریت می‌کنه، ولی برای پایداری بیشتر Railway گزینه‌ی بهتریه.

## نکته حقوقی

دانلود محتوا ممکنه با شرایط استفاده‌ی یوتیوب/اینستاگرام یا حق کپی‌رایت صاحب اثر در تضاد باشه. این ابزار رو فقط برای محتوایی استفاده کن که اجازه‌ی دانلودش رو داری (مثلاً محتوای خودت یا محتوای با مجوز آزاد).
